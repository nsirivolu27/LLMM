# Archived LNKZ geo-social prototype

This directory preserves LNKZ's original location-based photo-sharing implementation: Django REST, FastAPI/Celery, PostGIS, and the Spring geo service. The matching uncommitted marketing site is preserved in `website-v1/`.

It is intentionally excluded from the active root build. Its original Docker Compose file and environment example remain here if the concept is revived later.
